# Garment reference library

Create one folder per catalog product ID, for example `assets/garments/p1/components/`. Store only approved garment reference images there using lowercase kebab-case names such as `front.webp`, `back.webp`, and `fabric-detail.webp`. Add a `metadata.json` beside `components/` with the product ID, garment type, and reference-image list. This library is separate from `assets/stock/` general site imagery.
